## 2026-06-18 - [Dynamic Image Upload UI A11y]
**Learning:** Icon-only buttons used for removing dynamic content (like uploaded images) often lack accessible labels, rendering them difficult for screen reader users to identify what image is being removed. Furthermore, dynamically populated image arrays often lack descriptive alt tags to distinguish the previewed contents. Lastly, such elements typically lack keyboard focus styles, which disrupts keyboard navigation users.
**Action:** Always provide dynamically generated `aria-label` tags (e.g. `aria-label={"Supprimer la photo " + (index + 1)}`) for icon-only action buttons. Ensure dynamic preview images have descriptive `alt` texts and implement `focus-visible` styling (e.g., `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-1`) for icon action buttons.
